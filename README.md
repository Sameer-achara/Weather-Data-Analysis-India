# 🌤️ India 50 Cities Weather & AQI Analytics Portal

An interactive Data Analytics Dashboard built using **Python, Pandas, Streamlit, Matplotlib, and Seaborn** to analyze weather conditions and air quality across 50 Indian cities.

The dashboard provides detailed insights into temperature trends, AQI patterns, rainfall statistics, humidity levels, wind speed analysis, and correlation studies through interactive visualizations.

## 📁 Dataset Information

The dataset contains weather and environmental information for 50 Indian cities.

### Dataset Columns

| Column Name | Description |
|------------|-------------|
| City | City Name |
| Day | Observation Day |
| Temperature | Average Temperature |
| Max_Temperature | Maximum Temperature |
| Min_Temperature | Minimum Temperature |
| AQI | Air Quality Index |
| Rainfall | Rainfall (mm) |
| Humidity | Humidity Percentage |
| Wind_Speed | Wind Speed (km/h) |

## ▶️ How to Run the Project

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/weather-analytics-dashboard.git
```

### 2️⃣ Install Dependencies

```bash
pip install pandas streamlit matplotlib seaborn
```

### 3️⃣ Run Application

```bash
streamlit run app.py
```

### 4️⃣ Upload Dataset

- Open the Streamlit application.
- Upload the weather dataset CSV file.
- Select a city or day filter.
- Explore insights and visualizations.
